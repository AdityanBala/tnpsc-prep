# tnpsc-prep

A phone-first study and mock-test site for the TNPSC Group 4 exam, in Tamil with an English switch.

- `index.html`, `app.js`, `style.css`, `config.js`: the site. No build step.
- `content/index.json`: the list of study days.
- `content/day-NNN.json`: one day's notes and tests.
- `tools/validate.py`: checks the content files. Run it before every commit.

This repository is public. It holds study material only: no keys, no names and no results.
